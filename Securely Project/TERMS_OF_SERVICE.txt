2. DESCRIPTION OF SERVICE
═══════════════════════════════════════════════════════════════════════════════

2.1. Securely is an AI-powered cybersecurity monitoring application designed to
     help protect users from phishing attacks, malware, malicious URLs, and
     other security threats by monitoring screen content in real-time.

2.2. Core Functionality:
     (a) Continuous screen monitoring using Optical Character Recognition (OCR)
         technology;
     (b) Real-time threat detection using keyword matching and AI analysis;
     (c) Visual threat indicators (optional hitbox overlay);
     (d) Desktop notifications for detected threats;
     (e) Audit logging of security events;
     (f) Integration with Google Gemini AI for advanced threat analysis.

2.3. Service Modes:
     (a) 24/7 Continuous Monitoring: Monitors screen content continuously while
         enabled;
     (b) Quick Scan: 15-minute focused security scan;
     (c) One-Shot Scan: Single immediate security analysis.

2.4. Securely operates by:
     (a) Capturing screenshots of your screen at regular intervals (approximately
         20 times per second);
     (b) Extracting visible text using OCR technology;
     (c) Analyzing content using keyword matching and AI-powered analysis;
     (d) Sending screen content to third-party AI services (Google Gemini) for
         threat analysis;
     (e) Displaying notifications and visual indicators when threats are detected.
