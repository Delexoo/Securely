What this app is

Goal. Ship Securely: a Windows desktop overlay that OCR’s the primary monitor, classifies phishing and scam UI through a server-side OpenRouter proxy, and unlocks with a $3/month Stripe subscription — an assistive decision aid, not antivirus.

Who it is for. Windows users who want on-screen warnings about phishing and scam UI before they click. No Securely account; activation is by email after Stripe checkout.

Checks that fit. Present: public marketing site, contact and billing forms, Stripe payments, serverless APIs (checkout, license, analyze, webhook), NuGet dependencies, HTTPS deploy on Vercel, desktop host + WebView UI. Not needed for this product: Securely accounts/login, app database/RLS, marketing email, analytics/cookies, blog, visitor UGC, file uploads to Securely servers, invented reviews/stats.

Based onREADME.md; package.json; SECURITY.md; Securely-Website/index.html, pricing.html, billing.html, billing-success.html, contact.html, privacy.html, terms.html, 404.html, error.html, releases.html, llms.txt, robots.txt, sitemap.xml, vercel.json, site.css, THIRD_PARTY_NOTICE.md, api/analyze.js, api/checkout.js, api/webhook.js, api/license.js; securely-app/README.md, host/SecurelyShell.csproj, ui/public/index.html, dashboard.js, securely.css; .env.example; .gitignore; .github/dependabot.yml.
