What this app is

Goal. Ship a Windows desktop overlay that watches the primary screen with OCR + AI, flags phishing and scam UI, and support it with a marketing site plus a server-side analyze API — without embedding provider keys in the client.

Who it is for. Consumers and individuals who want assistive, real-time screen threat warnings on Windows (security teams are mentioned in marketing copy).

Checks that fit. Public marketing pages, dependency manifests, a paid LLM analyze API, and pricing/payment promises apply. Forms, accounts, blog, analytics, email marketing, uploads, UGC, and a real app database do not fit the shipped surface yet. Payments apply because pricing UI promises paid plans even though Stripe code is largely missing.
