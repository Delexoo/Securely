FAQ

Common questions

Does Securely send screenshots to the cloud?

By default the analyze path sends OCR text, not full screenshots. OCR text can still contain sensitive content — review the Privacy Policy.

Is Securely a guarantee against phishing?

No. It is an assistive tool. False positives and missed threats are possible. See the AI limitations in Terms.

Which AI provider do you use?

OpenRouter, selected server-side. Keys are not embedded in the Windows app.

Do I need a Securely account?

No. Pay $3/month with Stripe using an email, then Activate that email in the app. Cancel anytime in Stripe’s customer portal.
