v0.1.5 22 Oct 2026

Instant billing unlock, broader privacy gate, power-suite research

Added

Core

Dashboard

  • After Stripe Checkout, the Credits tab flips to Active immediately via checkout-status, opener postMessage, and a short license poll — no manual re-activate wait.

API

Site

  • Billing success auto-confirms the session and posts securely-checkout-done back to the opener dashboard.
  • docs/power-suite research pack maps Analyze, Defender-companion AV, WireGuard VPN, and real-time roadmap with a Phase 1 build prompt.

Security

  • Threat model documents Analyze/VPN/AV data flows and honest claim limits versus Norton-class suites.
  • REA use is bounded to Securely and open targets — never commercial AV/VPN binaries.

Bug fixes

Dashboard

  • Subscribe opens checkout without noopener so the success page can notify the dashboard.
v0.1.4 22 Oct 2026

Local sensitive-data gate before AI scan

Added

Core

  • Quick Scan runs a local detector for passwords, SSNs, payment details, and addresses before any AI upload.
  • If sensitive text is found, the pill prompts Stop or Continue — Continue redacts OCR and sends text only (no screenshot) to AI.
  • OCR+AI remains the classifier; local phishing cues and a one-retry analyze call harden reliability when OCR is strong.

Security

  • Sensitive screens are never uploaded unless the user explicitly continues after the local privacy warning.

Bug fixes

Core

  • Screen capture JPEG quality and width are raised slightly so Windows OCR reads more reliably.
